Codeforces Analytics — Neo Glass

«A modern Chrome extension that turns Codeforces profiles into interactive analytics dashboards.»

Codeforces Analytics — Neo Glass adds an interactive analytics dashboard directly to Codeforces profile pages.

It uses the official Codeforces API to retrieve public submission data and presents statistics such as solved problem ratings, tags, and other profile insights through interactive charts and a modern Neo Glass interface.

✨ Features

- 📊 Problem Ratings — Visualize the distribution of solved problems by difficulty.
- 🏷️ Tags Solved — See which problem tags you have practiced the most.
- 📝 Unsolved Tracker — Quickly access problems that you have not solved yet.
- 📸 One-Click Image Export — Export your statistics as a high-resolution image.
- 🌐 Multilingual Interface — English, 中文, فارسی, and हिन्दी.
- 🌓 Dark / Light Theme — Switch between Neo Glass Dark and Neo Glass Light.
- 🧊 Neo Glass UI — A clean, modern glassmorphism-inspired interface.
- ⚡ No Backend Required — Data is processed directly in the browser.

🔐 Privacy

Privacy is an important design consideration of this project.

- All processing happens locally in the browser.
- Only publicly available Codeforces data is requested.
- Data is retrieved through the official Codeforces API.
- No personal data is collected by a backend server.
- No user data is intentionally sent to third-party servers by this extension.

🚀 Installation

The extension is currently not published on an extension store, so it can be installed manually.

Chrome / Chromium-based browsers

1. Download or clone this repository.
2. Open:

chrome://extensions

3. Enable Developer mode.
4. Click Load unpacked.
5. Select the downloaded repository folder.
6. Open any Codeforces profile page.

The analytics dashboard should appear automatically.

Microsoft Edge

You can follow the same process through:

edge://extensions

and enable Developer mode.
